# Operate

Operating Khone means tuning each route to the workload and watching the gateway and target Lambda
signals together.

- [Tune batching](tune-batching.md): set wait windows, batch sizes, tenant keys, and timeout bounds.
- [Observability](observability.md): enable traces, EMF metrics, profiling metrics, and debug headers.

Benchmark setup and public result interpretation live under [Benchmarks](../benchmarks/index.md).
