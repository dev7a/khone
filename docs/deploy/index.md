# Deploy

Deployment is split between account-level bootstrap resources and application-owned gateway stacks.

- [LMI deployment model](lmi-deployment-model.md): how the bootstrap stack, gateway Lambda, Function
  URL, and LMI capacity provider fit together.
- [Example templates](examples.md): deploy one included example by integration mode and language.
- [SAM gateway](sam-gateway.md): define a gateway function and config resource in your own stack.

If this is your first deployment, start with the [Quickstart](../start/quickstart.md).
